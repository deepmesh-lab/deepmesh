# 사이드카 없는 배포본

여기 있는 매니페스트는 `k8s/<서비스>/deployment-with-sidecar.yaml`과 **같은 이름의
Deployment를 정의한다**. 사이드카(탐지)를 뺀 판이라, 프록시 없이 MSA만 띄워 확인할 때
쓴다.

서비스 디렉터리에서 여기로 옮긴 이유는 하나다. 같은 디렉터리에 두면
`kubectl apply -f k8s/auth-service/`가 두 파일을 모두 적용하고, 나중에 적용된 쪽이
이긴다 — 파일명 정렬상 사이드카 없는 쪽이 나중이라, **탐지가 조용히 꺼진 채로 배포된다**.
클러스터는 정상으로 보이고 대시보드만 비어서, 원인을 찾기 어렵다.

그래서 기본 배포 경로(`k8s/` 아래 서비스 디렉터리)에는 사이드카 있는 판만 남긴다.
이쪽을 쓰려면 파일을 직접 지정한다:

```sh
kubectl apply -f k8s/no-sidecar/auth-service-deployment.yaml
```

되돌릴 때는 사이드카 있는 판을 다시 적용하면 된다. 같은 Deployment를 덮어쓰므로
따로 지울 필요는 없다.
